# Task 1 - Netflix Data Cleaning & Preparation

## Objective
Clean and prepare the Netflix dataset for further data analysis.

## Tools Used
- Python
- Pandas
- VS Code

## Dataset
Netflix Titles Dataset

## Work Completed
- Imported the Netflix dataset using Pandas
- Checked dataset shape and column names
- Checked missing values
- Checked duplicate records
- Converted date_added into datetime format
- Extracted duration values
- Standardized duration units
- Checked rating values
- Checked content types
- Checked country values
- Performed final data quality checks
- Exported the cleaned dataset

## Final Data Quality
- Rows: 8,790
- Columns: 12 after adding cleaned duration fields
- Missing values: 0
- Duplicate rows: 0
