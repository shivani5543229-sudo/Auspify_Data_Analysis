# Auspify Technologies Internship – Task 4

## Task Title
Trend Analysis by Release Year

## Objective
Analyze how Netflix content production has changed over time.

## Dataset
Netflix Titles Dataset

## Work Performed
- Loaded the cleaned Netflix dataset using Pandas.
- Organized content by release year.
- Calculated yearly content releases.
- Identified the peak release year.
- Created a trend visualization.
- Generated business insights.

## Key Business Insights
- The peak content release year is 2018.
- The highest number of titles released in a year is 1146.

## Trend Observation
- Netflix content releases increased significantly in the later years and reached a peak in 2018.
- After 2018, the number of titles declined through 2021.
- The trend shows strong content growth in the years leading up to 2018, followed by a decline in the latest years available in the dataset.

## Tools Used
- Python
- Pandas
- Matplotlib

## Output
The analysis successfully generated the yearly Netflix content release trend chart and supporting analysis screenshot.
